# Scary_tale
Проект Воропаева Артёма и Кузнецова Максима. Игра - головоломка.

Цель: Создать 2D приключенческую игру в мрачной сказочной атмосфере с головоломками, диалогами и инвентарем, используя модуль arcade в Python 3.

Разработчики: Воропаев Артём и Кузнецов Максим
Бета-тестер: Zeropoint
